# Deployment Checklist

## Power BI Desktop

- [ ] Open the `.pbix` file.
- [ ] Confirm the report title and page names are clean.
- [ ] Confirm all cards display correct formatting.
- [ ] Check slicers and interactions.
- [ ] Confirm fraud rate and risk rate are formatted as percentages.
- [ ] Confirm transaction amounts are formatted consistently.
- [ ] Remove any unused pages, messy test visuals, or temporary notes.
- [ ] Export or screenshot the two main report pages:
  - Fraud Monitoring Overview
  - Fraud Risk Analysis

## Power BI Service

- [ ] Publish report from Power BI Desktop to Power BI Service.
- [ ] Open the report in Power BI Service.
- [ ] Test the report online.
- [ ] Use Publish to web only if you are comfortable making the report and underlying model publicly accessible.
- [ ] Copy the public report URL.
- [ ] Paste the URL into the README under "Live report."

## GitHub

- [ ] Create folder: `Fintech_Transaction_Fraud_Analytics`.
- [ ] Upload README.md.
- [ ] Upload `/sql` folder.
- [ ] Upload `/docs` folder.
- [ ] Upload selected `/data_exports` files.
- [ ] Upload dashboard screenshots.
- [ ] Do not upload the full `.pbix` if it is over GitHub's normal file-size limit.
- [ ] Commit message suggestion: `Add digital banking fraud analytics project`
